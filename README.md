### 👥 2. HR Analytics – Employee Attrition Analysis

An employee analytics project using Python and Pandas to clean, transform, and analyze HR data, identify workforce trends, and explore factors influencing employee attrition.

**Tools & Skills Used:**
- Python
- Pandas & NumPy
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Power BI
- Data Visualization

**Project Highlights:**
- Analyzed an HR dataset containing 1,470 employee records and 35 columns.
- Cleaned and transformed employee data using Python.
- Created additional analytical columns, including AgeGroup, IncomeGroup, and Attrition Flag.
- Identified 237 employee attrition cases, representing an attrition rate of 16.12%.
- Prepared a detailed Exploratory Data Analysis report.
- Power BI dashboard development is in progress.

🔗 **Repository:** [HR Analytics – Employee Attrition](https://github.com/aryanaik1/HR-Analytics-Employee-Attrition)
